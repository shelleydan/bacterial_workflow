ANVIO Tutorial

# Running General Analysis and Visualisation

1. Edit the ANVIO.config in you working directory, provide paths relevant to your own genomes. 

2. Run 001_ANVIO_ANALYSIS.sbatch - Depending on the number of genomes, this might take a while. 

3. Check the job output files to check if the run was successful.

4. [OPTIONAL] ANVIO provides a FastANI Analysis which is extra, run 002_ANVIO_FastANI.sbatch.

5. [OPTIONAL] To include any metadata (e.g. sample site), run 003_ANVIO_Metadata.sbatch.

6. Investigate the out file generated by 001_ANVIO_ANALYSIS.sbatch to find instruction to launch the interactive window. 

7. In the interactive tool in your browser, customise to your hearts content. 

~~~~~ You can stop here ~~~~~

8. [OPTIONAL] Add gene clusters to a bin (write click to begin range, left right click to add in range items to bin), save the bins in a collection. 

9. [OPTIONAL] Modify the collection name and bin name as you have assigned, and run 005_ANVIO_CHECK_BINS.sbatch to first check if they were saved correctly. 

10. [OPTIONAL] Run 006_ANVIO_SEQUENCE_EXTRACT.sbatch to extract the DNA sequence of the specific bin.
